# 天线设计需求确认清单（Design Intake Checklist）

> 用途：用户提出「帮我设计一副天线」时，**先让用户按本清单确认需求，再动手建模**。
> 多波段天线的馈电拓扑、振子直径等细节会根本性地改变设计结果（本项目实测：
> 同一套尺寸从「三路独立馈电」改成「并联到单巴伦」，10 m 波段 SWR 从 1.8 恶化到 10+）。
> 用户不填的项按「默认值」列处理，并在交付时说明。

## A. 电气指标

| # | 项目 | 说明 / 默认值 |
| --- | --- | --- |
| A1 | 工作波段 / 中心频率 | 可多选（如 10 m: 28.0–29.7 MHz），注明优先级 |
| A2 | 带宽目标 | 窄带（只覆盖 CW 或 SSB 子段）/ 全波段 / 宽带 |
| A3 | 目标 SWR 与参考阻抗 | 默认 Z0 = 50 Ω、全段 SWR ≤ 2.0；可要求 ≤ 1.5 |
| A4 | 增益目标 | dBi，或「尽量高/接受 2 单元水平」 |
| A5 | 前后比要求 | 默认不约束；DX 用途建议 ≥ 12 dB |
| A6 | 发射功率 | 影响巴伦、母排与间隙的耐压选型，默认 ≤ 1 kW |

## B. 结构与机械

| # | 项目 | 说明 / 默认值 |
| --- | --- | --- |
| B1 | 单元数上限 | 每波段 2 / 3 / 更多 |
| B2 | boom 最大长度 | 受塔与转动半径限制 |
| B3 | 全尺寸还是缩短型 | 缩短型需确认：端帽（capacity hat）/ 加感线圈 / 线性负载 |
| B4 | 振子直径 | **均匀**（给管径，如 φ20 mm）还是**变径**（给每段「直径 × 长度」表） |
| B5 | 材料与壁厚 | 默认铝 6061/6063-T6（σ=3.54e7 S/m）；铜/不锈钢请注明 |
| B6 | 架设高度与地面 | 自由空间 / 离地 H m（εr、σ 可取平均地 13 / 0.005） |
| B7 | 风载 / 转动半径限制 | 冰风地区需单独校核 |

## C. 馈电（★ 多波段天线必须逐项确认）

| # | 项目 | 选项 |
| --- | --- | --- |
| C1 | 单波段匹配方式 | 直接 50 Ω / gamma / hairpin（β 匹配）/ T 匹配；巴伦类型（1:1 电流型等） |
| C2 | 多波段馈电拓扑 | **a)** 每波段独立馈线 + 天线开关；**b)** 所有驱动单元硬并联到同一个巴伦（母排/铜排连接，单根馈线）；**c)** 开套筒（open-sleeve）耦合馈电；**d)** 陷波器（trap）共用振子 |
| C3 | 并联馈电细节（选 b 时） | 母排截面与间距、母排距振子面高度、**馈点接在哪个驱动单元上**（如 XR3C 接在 20 m 驱动中心）、母排材质（铜排/铝排） |
| C4 | 共模抑制 | 默认建议在巴伦下端加共模扼流圈；不需要请注明 |

## D. 输出物

| # | 项目 | 默认 |
| --- | --- | --- |
| D1 | NEC 模型文件（.nec） | 总是交付 |
| D2 | 几何尺寸表 + 示意图 | 总是交付 |
| D3 | SWR / 增益 / 前后比 / 效率扫频曲线 | 默认交付 |
| D4 | 方向图（极坐标切面 + 3-D） | 默认交付 |
| D5 | 架高对比（5/8/10 m 真实地面） | 可选 |
